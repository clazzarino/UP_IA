# Detección de insatisfacción de pasajeros (Invistico Airline)

# Grupo 1

## Contenido
`TP_IA_insatisfaccion_pasajeros.ipynb`: Notebook en R: EDA, árbol de decisión (`rpart`), red neuronal chica con dropout (`torch` + `luz`) y comparación
`Invistico_Airline.csv`: Dataset (129.880 pasajeros, 23 columnas). 

Se puede ejecutar en Colab, en el entorno de ejecución R
La instalación de los paquetes (como `torch`) puede demorar algunos minutos
Requiere tener el archivo .csv subido a la sesión.

## Fuente de datos
Jana, S. *Airlines Customer Satisfaction*. Kaggle. https://www.kaggle.com/datasets/sjleshrac/airlines-customer-satisfaction
